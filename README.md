# Сайт управления потребительского рынка Одессы

Готовая статическая копия сайта для GitHub Pages. Включён раздел ЦНАП из последней сохранённой версии. Серверная часть и установка программ не нужны.

## Загрузка через браузер

1. Распакуйте архив на компьютере.
2. На https://github.com/new создайте отдельный репозиторий `odesa-consumer-market`.
3. Для бесплатного GitHub Pages выберите Public. Это сделает файлы общедоступными. Включите Add a README file и создайте репозиторий.
4. Откройте Add file → Upload files. Загрузите содержимое распакованной папки целиком, включая `.nojekyll`. Загружайте сами файлы, а не ZIP. Файл `index.html` должен находиться в корне репозитория.
5. Сохраните изменения в ветку main кнопкой Commit changes.
6. Откройте Settings → Pages. В Source выберите Deploy from a branch; ветка main, папка /(root). Нажмите Save.
7. После завершения публикации адрес сайта появится в Settings → Pages.

Если репозиторий пустой и кнопки Add file нет, используйте ссылку uploading an existing file.

## Редактирование

Тексты находятся в HTML-файлах. Например: контакты — contacts.html, сотрудники — management.html, ЦНАП — cnap.html. Оформление — style.css, поведение меню и поиска — site.js. Изменения файлов в выбранной ветке GitHub Pages публикуются автоматически. Копия на GitHub и сайт в ChatGPT Sites обновляются отдельно.

Это демонстрационный проект. Сведения, даты проверки и ссылки на официальные источники сохранены на страницах сайта.
